# jahsloveukpong.github.io

Portfolio site of Jahslove Ukpong, Network Engineer working toward cloud security.

## Updating projects and skills

Open `index.html` and find the block marked **EDIT HERE** near the bottom of the file.

- **Add a project:** copy one block in `PROJECTS`, paste it at the top of the list, and change the text.
- **Update a skill:** change its `status` to `"up"`, `"lab"` or `"next"` in `SKILLS`.

Commit the change, and GitHub Pages republishes the site within a minute or two.
